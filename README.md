# Rail Dial 1.1.0

**AOD 디자인을 항상 표시하는 별도 버전:** [Rail Dial AOD 1.0.1](aod/README.md). 기존 워치페이스와 함께 설치할 수 있습니다.

Wear OS 4 이상용 개인 워치페이스입니다. 다크/라이트 테마와 선택 가능한 붉은 원판 초침을 사용합니다. 기본값은 검은 바탕과 초침 꺼짐입니다.

- 절전 화면(AOD)은 검은 바탕과 얇은 회색 시침·분침만 표시합니다.
- 시각은 워치 시스템 시간을 사용합니다. 네트워크·위치·개인정보 권한은 요청하지 않습니다.
- 공식 Mondaine/SBB 제품이 아닙니다. 철도 시계의 2초 정지 동작은 구현하지 않았습니다.


## 1.1.0 변경 사항
- 시계 화면을 길게 누른 뒤 **꾸미기 → 화면 색상**에서 다크/라이트를 선택합니다. **초침 표시**를 켜면 1초 간격으로 움직이는 초침이 나타납니다.
- 시침·분침은 정수 시각·분 데이터만 사용합니다. 초침을 끄면 초/밀리초 데이터와 애니메이션을 사용하지 않습니다.
- AOD에서는 테마·초침 설정에 관계없이 기존의 검은 바탕·얇은 회색 바늘만 표시합니다.
- 바늘의 투명 여백을 잘라내고, 정적 배경 뒤에 바늘을 배치합니다.
- 이는 절전을 위한 설계 변경입니다. 사용자 워치에서의 급격한 배터리 소모 원인이나 개선율은 아직 확인하지 못했습니다.
- 설치 후 **개발자 옵션 → 무선 디버깅·ADB 디버깅 끄기**. 같은 밝기·AOD 설정에서 기본 삼성 시계 화면과 배터리 사용량을 비교해야 원인 구분이 가능합니다.

## 서명 및 설치 주의
이번 배포부터 별도로 보관한 고정 배포용 키를 사용합니다. 이전 1.0.2 개발용 APK와 서명이 다르므로 **기존 Rail Dial을 한 번 삭제한 뒤 설치**해야 합니다. 별도 앱인 Rail Dial AOD에는 영향을 주지 않습니다.

GitHub Actions 산출물의 `-unsigned.apk`는 서명 전 빌드입니다. 직접 설치하지 마세요. 사용자에게 제공하는 최종 파일은 별도 보관한 키로 서명·검증한 APK입니다. 개인 키와 비밀번호는 이 공개 저장소에 두지 않습니다.

## APK 빌드
이 파일과 `app/`, `.github/`, Gradle 설정을 저장소 최상단에 둡니다. 기본 브랜치 `main`에 반영하면 Actions의 **Build Wear OS APK**가 실행됩니다. 수동 실행도 가능합니다.
성공한 실행 화면 하단의 **rail-dial-1.1.0-unsigned-build**에는 서명 전 APK, 패키지 정보, SHA-256 해시가 들어 있습니다. 배포 APK는 별도 보관한 고정 키로 서명합니다.

## 설치 대상
이 APK는 갤럭시 워치4 이후 중 Wear OS 4 이상인 **워치에 직접 설치**합니다. 휴대전화에서 APK를 누르는 것으로 워치에 설치되지 않습니다. 워치 무선 디버깅에 연결해 `adb install -r rail-dial-1.1.0.apk`를 실행한 뒤, 워치의 시계 화면 선택 목록에서 **Rail Dial**을 선택합니다.

## 로컬 빌드
JDK 17, Gradle 8.11.1, Android SDK 플랫폼 36 및 빌드 도구 35.0.0이 필요합니다.
`gradle :app:assembleRelease`

## 확인 상태
Google 공식 WFF v1 XSD를 XSD 1.1 검증기로 검사했습니다. `check_faces.py`로 테마·초침·AOD 분기, 회전 중심, 기본 설정에서 초 단위 변경이 없음을 확인하고 렌더링한 미리보기를 검토했습니다. 이는 실제 Wear OS 실행 검사나 배터리 측정은 아닙니다. 실제 갤럭시 워치 설치·실행과 배터리 비교 측정은 아직 확인하지 못했습니다.

## Windows에서 직접 설치
1. Google의 [SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)에서 Windows용 도구를 내려받아 압축을 풉니다. 그 폴더에 `rail-dial-1.1.0.apk`도 둡니다.
2. 워치와 PC를 같은 Wi-Fi에 연결합니다. 워치 **설정 → 워치 정보 → 소프트웨어 정보 → 소프트웨어 버전**을 5회 눌러 개발자 옵션을 켭니다.
3. **개발자 옵션 → ADB 디버깅 / 무선 디버깅**을 켜고 **새 기기 페어링**에 표시되는 주소·포트·코드를 확인합니다.
4. 도구 폴더에서 터미널을 열고 아래 명령을 순서대로 실행합니다. `<...>`는 워치 화면의 실제 숫자로 바꿉니다. 페어링 포트와 연결 포트는 다릅니다.

```powershell
.\adb.exe pair <워치IP>:<페어링포트>
.\adb.exe connect <워치IP>:<연결포트>
.\adb.exe -s <워치IP>:<연결포트> install -r .\rail-dial-1.1.0.apk
```

첫 명령에서 코드를 물으면 워치의 페어링 코드를 입력합니다. `Success`가 나오면 워치의 시계 화면을 길게 눌러 **시계 화면 추가 → Rail Dial**을 선택합니다. 끝나면 워치의 ADB·무선 디버깅을 끕니다.
